# NextBlog

A modern, server-rendered blogging platform built to deliver fast initial load times and a seamless content management experience.

## Core Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Database & ORM:** PostgreSQL with Drizzle ORM
- **Authentication:** Auth.js
- **Runtime & Package Manager:** Bun

## Local Development

1. Install dependencies:
   ```bash
   bun install
   ```
2. Configure your environment variables (refer to .env.example)
3. Start the development server:
   ```bash
   bun dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view the application.
